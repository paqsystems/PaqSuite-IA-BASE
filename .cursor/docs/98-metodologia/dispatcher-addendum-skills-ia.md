# Addendum al Dispatcher - Skills de control IA

## Nuevos puntos recomendados

### A1 - Revisión de ambigüedad del SPEC

Después de `openspec-01` y antes de `openspec-02`.

```text
/spec-ambiguity-review
```

Bloquea HU si el SPEC permite interpretaciones distintas.

---

### B1 - Enriquecimiento de HU desde SPEC

Después de `openspec-02` y antes de `openspec-03`.

```text
/enrich-user-story
```

Solo puede enriquecer usando el SPEC.

---

### C1 - Validación pre-TR

Antes de cerrar TR, verificar:

- SPEC relacionada.
- HU relacionada.
- discrepancias documentadas.
- criterios verificables.

---

### D1 - Planificación IA

Antes de implementar TR.

```text
/ai-planning-mode
```

---

### F1 - Verificación del agente

Después de implementar y antes de `openspec-05`.

```text
/agent-verification-guide
```

---

### N1 - Reporte PR

Antes o durante Parte N.

```text
/write-pr-report
```
