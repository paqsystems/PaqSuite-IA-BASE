# Clasificación para retenciones

A través de este proceso podrá crear, modificar o eliminar clasificaciones, las cuales se asignan a los proveedores y a las retenciones de tipo 'Otras', para determinar la base de cálculo a aplicar.

Las clasificaciones definidas en este proceso se vinculan con las retenciones que utilizan bases de cálculo por clasificación, permitiendo aplicar distintos criterios de cálculo según el proveedor.

Consideraciones:

  * El código de clasificación no puede repetirse.
  * La clasificación es requerida para aquellos proveedores que tengan habilitada la opción Aplica retenciones en los pagos.
  * En caso de no existir una base de cálculo para la clasificación asignada, la retención podrá calcularse en 0.



Para más información consulte la [guía de implementación sobre bases de cálculo para retenciones tipo Otras](?p=16557).
