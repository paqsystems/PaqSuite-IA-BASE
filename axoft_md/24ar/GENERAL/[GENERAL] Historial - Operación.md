# Historial - Operación

Los procesos registran automáticamente las modificaciones que realicen todos los usuarios, ya sean altas, bajas o modificaciones; para este último caso detallamos el valor actual y el anterior correspondiente a cada cambio.

Para acceder a esta información pulsá el botón "Historial" sobre la barra de herramientas de cada proceso.  
Podés consultar las modificaciones realizadas al registro activo o a todos los registros para un rango de fechas y un usuario determinado.  
También registramos las actualizaciones de información procedentes de [API](https://ayudas.axoft.com/24ar/api_oper) y [Excel](https://ayudas.axoft.com/24ar/excel_oper), detallando el origen (o proceso) desde donde se produjo el cambio.  
Si ingresás como usuario "Supervisor" podrás acceder a la configuración del historial para indicar si ese proceso debe ser auditado (por defecto todos lo son) o para eliminar la información de auditoría registrada para un usuario o rango de fechas determinado.  
Si no querés registrar el historial de cambios de ningún proceso ingresá al proceso [Datos de la empresa](?p=11851) y destildá la opción Registra auditoría dentro de la solapa Mas datos.

Registra auditoría (solo procesos web): al activar esta opción, los procesos que están disponibles desde el navegador guardarán en el historial del sistema cada modificación realizada, a fin de tener la posibilidad de consultarlos posteriormente. Si destildás esta opción ningún proceso registrará el historial de cambios independientemente de lo que configurado en cada uno.

__Nota

Tené en cuenta que para el caso de [vistas](?p=38887) no registramos el detalle de las modificaciones realizadas. Es decir, al igual que en cualquier otro proceso, auditamos las creaciones, modificaciones y eliminaciones de registros pero para este concepto caso no almacenamos el detalle de cada modificación.
