# Guía sobre bases de cálculo para retenciones tipo Otras

El sistema permite la definición de la base de cálculo de las retenciones del tipo 'Otras' según la clasificación del proveedor.

##### Puesta en marcha

  1. **Definición de clasificación:** ingrese al proceso [Clasificación para retenciones](?p=18366) para crear una nueva.
  2. **Configuración de la retención:**
     1. Ingrese al proceso [Retenciones](?p=14619).
     2. Defina una retención del tipo 'Otras' y active el parámetro Utiliza bases de cálculo según clasificación del proveedor.
     3. En la solapa Base de cálculo, defina la configuración correspondiente.
  3. **Asociación al proveedor:**
     1. Ingrese al proceso [Proveedores](?p=14686).
     2. Edite el proveedor y asigne, en la solapa Impuestos, el Código de clasificación.



Al generar los pagos que calculan retenciones de tipo 'Otras', se considera el código de clasificación asignado al proveedor para determinar la base de cálculo a aplicar.
