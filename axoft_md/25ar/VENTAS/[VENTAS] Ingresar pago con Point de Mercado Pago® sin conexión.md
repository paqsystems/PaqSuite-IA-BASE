# Ingresar pago con Point de Mercado Pago® sin conexión

Si no es posible confirmar, mediante el servicio con Tango Cobranzas, el estado del pago realizado, elimine el medio de pago y seleccione manualmente la cuenta que se definió en [Preferencias](?p=18387) para los pagos realizados mediante Mercado Pago®.

Al pie podrá ingresar el número de transacción del pago a fin de tener el registro al momento de realizar una conciliación.

**Ejemplo...**

Se está generando un comprobante por $1,500. El vendedor, desde la ventana de solicitud de pago, confirma el importe a cobrar en el dispositivo Point, con _< F10>_ hace el envío de la solicitud a Mercado Pago®, pero al verificar si se realizó el pago, el sistema muestra que no hay conexión a Internet.

En este caso el vendedor debe eliminar el medio de pago Mercado Pago® Point de la selección y agregar, entre los medios disponibles, la cuenta que está definida como la que agrupará todos los pagos que se realicen con el dispositivo Point.
