# Parametrización contable en Ventas - Clientes potenciales

En este proceso puede asociar a un cliente potencial una cuenta contable particular, con su detalle de auxiliares, reglas manuales o automáticas, que serán tenidos en cuenta cuando se cree como cliente habitual.

Invoque esta opción si previamente definió la integración con el módulo Contabilidad, configuración que se realiza desde [Herramientas para integración contable](?p=11936) en el módulo Procesos generales.
