# Tarjetas

Usted podrá registrar los nombres de las entidades de tarjeta de crédito y débito con las que realiza habitualmente operaciones comerciales de ventas.

Código de la tarjeta: en este campo podrá indicar un valor de hasta tres caracteres de tipo alfanumérico.

Tipo: este campo le permitirá indicar si la tarjeta que esta dando de alta es del tipo 'Débito' o 'Crédito'.

__Nota

Este campo será requerido si usted configura modalidad shopping para **Grupo IRSA - Interfaz Fiser**.

Descripción: ingrese un nombre o leyenda con la cual identificará la tarjeta.

__Nota

Varias cuentas pueden estar asociadas al mismo código de tarjeta. Estos códigos son necesarios al definir los planes de tarjetas en el proceso [Cuentas](cuentacaja_gv3).
