# Modificación de comprobantes Restô

Este proceso permite modificar algunos datos de los comprobantes emitidos.

Es posible modificar:

  * Tipo de asiento
  * Contabilizado
  * Observaciones
  * Detalle de Cuotas de facturas
  * Clasificación SIAp



En el caso de recibos, sólo es posible modificar el campo:

  * Observaciones
