# Agrupaciones de artículos

Este proceso permite definir un nombre para cada agrupación de los códigos de artículo, es decir para cada familia y grupo.

El Código de Agrupación tendrá una longitud igual a la definida en el proceso [Longitud de Agrupaciones](https://ayudas.axoft.com/25ar/longitagrupacion_st).
