# Formularios gráficos de Stock

Este proceso permite configurar los formularios gráficos para comprobantes de Stock utilizando una fuente de datos o diccionario con los campos disponibles.

##### Principal

Código: cada modelo que usted defina se identificará por este código. Será posible ingresar hasta 10 caracteres.  
El sistema valida que sea único, es decir, que no se repita en dos formularios.

Descripción: en este campo podrá ingresar una descripción o referencia. Su ingreso es opcional.

Habilitado: esta opción indica si el formulario está habilitado o no para generación de PDF. Por defecto estará activado.

Tipo de formulario: en esta opción podrá seleccionar el tipo de movimiento al que pertenece este formulario.

##### Diseño

En esta sección usted puede editar el diseño del formulario gráfico que se utilizará en la generación de PDF con los datos relacionados al comprobante de stock.  
Los campos disponibles se muestran agrupados dentro del árbol de Fuentes de datos. Algunos ejemplos de estos grupos son: 'Encabezado', 'Renglones', 'Partidas', 'Series' y 'Totales'.  
Para más información, puede consultar:

  * [Campos disponibles para ingresos de stock](?p=14423).
  * [Campos disponibles para egresos de stock](?p=14435).
  * [Campos disponibles para ajustes de stock](?p=26604).
  * [Campos disponibles para transferencias entre depósitos](?p=27255).



**Botón Modelos <Alt + M>**  
Al presionar "Nuevo" se habilita un botón en la barra de botones en el encabezado llamado “Modelos”. Esta opción le permite seleccionar un diseño de formulario gráfico provisto por el sistema, sirviendo como plantilla para luego modificarlo según lo que necesite.
